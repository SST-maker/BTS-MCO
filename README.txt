# MCO Quiz Arena — V1

Cette V1 est un prototype web/PWA de quiz "style Kahoot" pour BTS MCO.

## Ce que contient cette version
- mode quiz solo / projection classe sur un seul écran ;
- banque de questions ADOC 1A / ADOC 2A / GO 1A / GO 2A ;
- filtres par niveau, matière et difficulté ;
- score + timer + progression ;
- correction pédagogique après chaque question ;
- revue finale des erreurs.

## Ce que cette version ne fait pas encore
- vrai mode multi-joueurs avec téléphones séparés et code de partie ;
- suivi nominatif des élèves ;
- statistiques par classe.

## Ouvrir l’application
Double-cliquer sur index.html ou héberger le dossier sur un petit serveur web.

## Prochaine étape possible
V2 = vrai mode prof/élèves en direct (join code / QR code / classement live / historique des résultats).
