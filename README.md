# NCR Solutions — MCO Quiz Arena V4

V4 = moteur multijoueur V3 + banque complète + direction graphique officielle validée.

## Inclus
- dashboard professeur clair avec sidebar
- création de quiz par niveau / matière / chapitre / leçon / difficulté
- modes Classe, Battle, Révision, BTS et Duel
- code de partie 5 caractères + QR code dynamique
- connexion élève sans compte
- lobby temps réel
- écran question projetable
- écran réponse mobile coloré
- chrono, rapidité, séries
- corrections pédagogiques
- classement live et podium
- export CSV
- mode Solo
- banque structurée
- PWA installable + icônes 64/180/192/512 + maskable
- responsive ordinateur / tablette / smartphone

## Banque
1 620 questions, 156 leçons, 52 chapitres, 4 parcours (ADOC/GO 1A/2A).

## Démarrage sur Mac
Double-clique `START_MCO_QUIZ.command`, puis ouvre l'adresse affichée. Pour les élèves sur le même Wi-Fi, utilise l'adresse Réseau dans le terminal ou le QR code du lobby.

## Limite actuelle
Les sessions sont en mémoire : elles disparaissent si le serveur redémarre. La banque de questions reste enregistrée dans les fichiers.
