# Supports visuels de questions

Tu peux déposer ici des images utilisées par les questions.

Exemple de valeur SQL pour `media` :

```json
[{"kind":"image","src":"./assets/questions/zone-chaude.jpg","alt":"Rayon d’un magasin","caption":"Observe l’implantation avant de répondre."}]
```

Pour une annexe PDF avec aperçu :

```json
[{"kind":"document","src":"https://.../annexe.pdf","preview":"./assets/questions/annexe-1.png","title":"Annexe 1","caption":"Tableau de bord commercial"}]
```
